# AI Video Studio · Public Demo

> 공개 데모 복사본입니다. 처음 실행하면 `가이드.aivworkflow.json`의 22개 노드 워크플로우가 기본 프로젝트로 열립니다. API 키, 로컬 모델과 개인 생성 결과는 포함하지 않습니다.

> 처음 설치하거나 집 PC에서 업데이트하려면 [집 PC 설치 및 업데이트 가이드](./집_PC_설치_및_업데이트_가이드.md)를 먼저 확인하세요.

> 로컬 TTS·BGM 모델은 Git에 포함되지 않습니다. [집 PC 로컬 AI 모델 설치 가이드](./집_PC_로컬_AI_모델_설치_가이드.md)에서 공식 다운로드 주소와 복구 순서를 확인하세요.

[전체 기능·설정·수정 가이드](./AI_STUDIO_기능_설정_수정_가이드.md)에서 각 탭, 워크플로우 노드와 개발자 수정 절차를 확인할 수 있습니다.

## 빠른 실행

1. 프로젝트 루트의 **START-STUDIO.cmd**를 더블클릭합니다.
2. 처음 실행할 때 필요한 Python·Node.js 의존성 설치와 Pixel Office 빌드가 끝날 때까지 기다립니다.
3. 브라우저에서 **http://localhost:8055**가 열리면 사용합니다.
4. 종료할 때는 실행 중인 검은 창에서 **Ctrl+C**를 누릅니다.

START-STUDIO.cmd 하나가 통합 Studio, Pixel Office, 설치된 로컬 TTS를 함께 준비합니다. 로컬 BGM은 BGM 탭에서 생성할 때 자동으로 실행됩니다. API 키는 프로젝트 루트의 .env에 저장하며 Git에는 포함되지 않습니다.

이미지 생성이 완료되면 결과가 이미지 생성 노드 전체에 즉시 미리보기로 표시됩니다.
입력 또는 출력 포트의 연결선을 빈 캔버스에 놓으면 연결 가능한 노드 목록이 열리며,
목록에서 고른 노드는 놓은 위치에 생성되고 기존 노드와 자동으로 연결됩니다.

사람이 AI 결과를 검토하고 수정할 수 있는 웹 기반 영상 프리프로덕션 도구입니다.

- 프로젝트 생성, 선택, 삭제

## 프로젝트 백업

사이드바의 `프로젝트 내보내기`를 누르면 선택 프로젝트와 관련 이미지를
`.aivstudio.json` 파일로 저장합니다. 다른 브라우저에서는 `프로젝트 가져오기`로
이 파일을 선택해 새 프로젝트로 복원할 수 있습니다.

이미지 파일은 브라우저의 IndexedDB에 저장되며, 프로젝트 데이터에는 이미지 ID와
메타데이터만 저장됩니다. 따라서 `localStorage` 용량 제한으로 여러 컷의 이미지가
저장되지 않는 문제를 줄였습니다.

## 실행 방법

이 프로젝트는 JavaScript ES Module을 사용하므로 `index.html`을 직접 더블클릭하지 마세요.
`file://` 주소에서는 브라우저가 모듈 파일을 차단할 수 있습니다.

가장 쉬운 방법은 `START-STUDIO.cmd` 파일을 더블클릭하는 것입니다.
검은 창에서 사용할 공급자의 API 키를 요청하면 붙여넣고 Enter를 누르세요.
사용하지 않는 공급자는 빈 상태로 Enter를 눌러 건너뛸 수 있습니다. 입력 문자는
화면에 표시되지 않습니다. 서버가 준비되면 브라우저가 자동으로 열립니다.

PowerShell에서 프로젝트 폴더로 이동한 후 다음 명령을 실행합니다.

```powershell
.\start-dev-server.ps1
```

OpenAI API 키가 환경변수에 없으면 실행 스크립트가 키를 비공개로 요청합니다.
입력한 키는 화면이나 프로젝트 산출물에는 포함되지 않습니다. 처음 입력한 API 키는 프로젝트
루트의 로컬 `.env` 파일에 저장되며 다음 실행부터 자동으로
불러옵니다. `.env`는 Git, 프로젝트 백업, 파일 탭과 브라우저 정적 파일 제공에서 제외됩니다.

이미지 모델별로 다음 환경변수를 사용합니다.

- GPT Image 2: `OPENAI_API_KEY`
- Claude 텍스트 모델: `ANTHROPIC_API_KEY`
- Nano Banana 2 / Nano Banana Pro: `GEMINI_API_KEY`
- Gemini 텍스트 모델: `GEMINI_API_KEY`
- APIFRAME Suno BGM 생성: `APIFRAME_API_KEY`
- Seedream 5.0 Pro: `ARK_API_KEY` (BytePlus ModelArk)
- WaveSpeedAI 영상 생성(Seedance): `WAVESPEED_API_KEY`

### Google Docs 연결

Google Cloud Console에서 Google Docs API를 활성화하고 OAuth 데스크톱 또는 웹 애플리케이션
클라이언트를 만듭니다. 웹 애플리케이션을 사용하는 경우 승인된 리디렉션 URI에 아래 주소를
등록하세요.

```text
http://localhost:8055/api/google/oauth/callback
```

`.env`에 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`을 한 번 입력한 뒤 서버를 다시 시작하고,
워크플로우의 Google Docs 노드에서 `Google 계정 연결`을 누르세요. 연결 후 발급되는
`GOOGLE_REFRESH_TOKEN`은 `.env`에 자동 저장되므로 다음 실행부터 다시 로그인할 필요가 없습니다.
권한은 Google Docs 읽기 전용만 요청합니다.

그다음 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8055
```

변경 내용이 바로 보이지 않으면 `Ctrl+F5`로 강력 새로고침하세요.
서버는 PowerShell 창에서 `Ctrl+C`를 눌러 종료할 수 있습니다.

PowerShell 실행 정책 때문에 스크립트 실행이 차단되는 경우 같은 PowerShell 창에서
API 키를 환경변수에 설정한 뒤 서버를 실행할 수 있습니다.

```powershell
$env:OPENAI_API_KEY = "발급받은 API 키"
$env:GEMINI_API_KEY = "발급받은 Gemini API 키"
$env:ARK_API_KEY = "발급받은 BytePlus ModelArk API 키"
python server.py
```
